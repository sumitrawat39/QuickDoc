# 👨‍⚕️ QuickDoc – Doctor Appointment Booking Platform

**QuickDoc** is a full-stack Doctor Appointment Booking platform designed to streamline healthcare access for patients, doctors, and administrators. It enables real-time, conflict-free appointment scheduling, secure authentication, and seamless payment integration — all within a modern, responsive interface.

---

## 🚀 Key Features

* ✅ **Real-time Appointment Booking** – Ensures clash-free scheduling
* 🔐 **Secure Authentication** – JWT-based login system for patients and doctors
* 💳 **Online Payments** – Integrated Razorpay payment gateway *(test mode)*
* 📱 **Responsive UI** – Optimized for mobile, tablet, and desktop
* 🧾 **User Experience Enhancements** – Toast notifications & intuitive navigation
* 📷 **Cloud Media Handling** – Image uploads managed via Cloudinary
